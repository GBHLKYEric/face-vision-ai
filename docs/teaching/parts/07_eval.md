### 知识要点 {#t7-s1}

**1. LFW 标准协议。** 官方 pairs.txt 给出 6000 对图片，分成 10 折，每折 300 对"同一人"+ 300 对"不同人"。评测时轮流用 9 折选阈值、在剩下 1 折上测准确率，10 次取平均。这样阈值从来没"见过"它要测的那部分数据，报告的准确率才可信。 {#t7-k1}

**2. 怎样选阈值。** 把 9 折的 5400 个相似度从小到大排序，阈值只需要在"相邻两个分数的中点"里挑——两个相邻分数之间移动阈值，预测结果不会变。排序后用前缀和一次算出所有候选阈值的准确率，复杂度 O(n log n)，比"从 −1 到 1 每隔 0.001 试一次"更精确也更快（见 `facevision/verification.py` 的 `best_threshold`）。 {#t7-k2}

**3. ROC 曲线与 AUC。** 阈值从高到低扫一遍，每个阈值得到两个数：TPR（同一人被判对的比例，通过率）和 FPR（不同人被误判成同一人的比例，误识率）。以 FPR 为横轴、TPR 为纵轴画出来就是 ROC 曲线；曲线下面积 AUC 越接近 1 越好，它和阈值无关，衡量的是模型"把正负样本分开"的整体能力。 {#t7-k3}

```latex
\mathrm{TPR}=\frac{TP}{TP+FN},\qquad \mathrm{FPR}=\frac{FP}{FP+TN},\qquad \mathrm{AUC}=\int_0^1\mathrm{TPR}\,d(\mathrm{FPR})
```

**4. TAR@FAR：工业界真正看的指标。** 准确率把"误识"和"拒识"同等对待，但在刷脸支付里，把陌生人认成你（误识）比让你多刷一次（拒识）严重得多。所以工业界先规定一个很低的误识率 FAR（如万分之一、百万分之一），再看此时的通过率 TAR。LFW 只有 3000 个负样本对，最低只能测到 FAR = 1/3000，所以本项目报告 TAR@FAR=10⁻³。 {#t7-k4}

**5. 等错误率 EER。** 调阈值使误识率 = 拒识率时的错误率，一个数概括 ROC 曲线，越低越好。 {#t7-k5}

**6. 检测指标：Precision、Recall、AP。** 检测框和真实框 IoU ≥ 0.5 才算找到。Precision = 检测出的框里有多少是对的；Recall = 真实的脸有多少被找到了。把检测分数阈值从高到低扫，得到 PR 曲线，曲线下面积就是 AP。WIDER FACE 把脸按大小、遮挡、姿态分成 Easy / Medium / Hard 三档：不在当前档里的脸算"忽略"，检测到也不加分、没检测到也不扣分（`facevision/widerface_eval.py` 逐行移植了官方评测脚本）。 {#t7-k6}

```latex
\mathrm{Precision}=\frac{TP}{TP+FP},\qquad \mathrm{Recall}=\frac{TP}{TP+FN},\qquad \mathrm{AP}=\int_0^1 P(R)\,dR
```

**7. 生成质量指标 FID。** 用 Inception 网络分别提取真实图片和生成图片的 2048 维特征，各自拟合成一个高斯分布，计算两个高斯之间的 Fréchet 距离。越小说明生成图片的"整体统计特性"越像真图。详见专题十一。 {#t7-k7}

```latex
\mathrm{FID}=\|\mu_r-\mu_g\|^2+\operatorname{tr}\Bigl(\Sigma_r+\Sigma_g-2(\Sigma_r\Sigma_g)^{1/2}\Bigr)
```

### 例题 {#t7-s3}

#### 例题 1|手算最佳阈值 {#t7-e1}

**6 对样本的相似度和标签：0.10(不同)、0.20(不同)、0.35(同)、0.30(不同)、0.60(同)、0.80(同)。求准确率最高的阈值。**

排序：0.10 不、0.20 不、0.30 不、0.35 同、0.60 同、0.80 同。阈值放在 0.30 和 0.35 之间，左边全是"不同"、右边全是"同"：

```latex
\text{thr}=\frac{0.30+0.35}{2}=\boxed{0.325},\qquad \text{准确率}=\frac66=100\%
```

真实数据里正负样本会有交叠，最优阈值处准确率达不到 100%，但找法一样：只试相邻分数的中点。

#### 例题 2|TAR@FAR=10⁻³ 是什么意思 {#t7-e2}

**LFW 有 3000 对不同人的样本。本项目 TAR@FAR=10⁻³ = 99.733%，怎么理解？**

FAR = 10⁻³ 允许 3000 × 0.001 = 3 对不同的人被误认成同一人。把阈值调到恰好只有 3 对误认的位置，此时 3000 对同一人里有 99.733%（2992 对）能通过。

```latex
\text{允许误认}=3000\times10^{-3}=3\ \text{对},\qquad \text{通过}=3000\times99.733\%=\boxed{2992\ \text{对}}
```

#### 例题 3|为什么不能在测试集上调阈值 {#t7-e3}

**如果直接在全部 6000 对上找最佳阈值，再在同样的 6000 对上算准确率，会怎样？**

阈值"看过"了答案，准确率会偏高（尤其是样本少的时候）。这就像考前拿到了考卷再复习。10 折交叉验证保证每一折的阈值都只由另外 9 折决定。同理，本项目在训练过程中每个 epoch 都会测一次 LFW 画曲线，但最终报告的是最后一个 epoch 的模型，而不是"LFW 最高的那个 epoch"——按测试集挑模型也是一种作弊。

面试答法：评测要严格隔离"选择"和"测试"：阈值、超参数、模型挑选都只能用训练/验证数据，测试集只在最后用一次。
