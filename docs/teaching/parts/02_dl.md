### 知识要点 {#t2-s1}

**1. 卷积：一个会滑动的"小模板"。** 3×3 卷积核在图上逐位置滑动，每到一处就把 9 个像素和 9 个权重对应相乘再相加，得到输出图上的一个数。同一个核在整张图上共用（参数共享），所以"眼睛"不管出现在哪里都能被同一个核认出来（平移等变）。一层有很多个核，每个核学一种图案：浅层学边缘和颜色，中层学眼角、鼻翼这样的局部部件，深层学"整张脸"。 {#t2-k1}

```latex
y_{c'}(i,j)=b_{c'}+\sum_{c=1}^{C_{\text{in}}}\sum_{u=-1}^{1}\sum_{v=-1}^{1}W_{c',c}(u,v)\,x_c(i+u,\,j+v)
```

**2. 池化与步长：让图变小。** 步长为 2 的卷积（或 2×2 最大池化）把特征图长宽减半，计算量降到 1/4，同时让后面每个格子"看到"原图更大的范围（感受野变大）。IResNet 一共下采样 4 次：112 → 56 → 28 → 14 → 7。 {#t2-k2}

**3. 激活函数：引入非线性。** 只有乘加的网络无论多少层都等价于一层线性变换。ReLU（负数变 0）最常用；人脸网络常用 PReLU：负半轴的斜率也可学习，保留了一点负数信息。 {#t2-k3}

**4. 批归一化 BN：让每层输入"规矩"。** 把一个 batch 里每个通道的值减去均值、除以标准差，再乘可学的 γ、加 β。好处：训练更稳，可以用更大的学习率，对初始化不敏感。推理时用训练期间统计的滑动均值 μ 和方差 σ²，它就变成了一个固定的线性变换——这正是专题八"BN 融合"能把它合并进卷积的原因。 {#t2-k4}

```latex
\hat x=\gamma\cdot\frac{x-\mu}{\sqrt{\sigma^2+\varepsilon}}+\beta
```

**5. 残差连接：深网络能训起来的关键。** 网络很深时，梯度一层层往回传会越来越小（梯度消失）。ResNet 让每个块输出 F(x) + x：块只需要学"在 x 基础上改多少"，而 + x 这条"高速公路"让梯度可以不衰减地直达浅层。 {#t2-k5}

```latex
y=F(x)+x\quad\Rightarrow\quad\frac{\partial L}{\partial x}=\frac{\partial L}{\partial y}\Bigl(\frac{\partial F}{\partial x}+1\Bigr)
```

那个 "+1" 保证了梯度至少原样传回去。

**6. 深度可分离卷积：手机端的省钱秘诀。** 普通卷积同时混合"空间"和"通道"；MobileNet 把它拆成两步：逐通道卷积（每个通道单独做 3×3）+ 1×1 卷积（只混合通道）。效果接近，计算量约降为原来的 1/9 + 1/C_out。 {#t2-k6}

**7. 交叉熵损失。** 分类网络输出每类的打分 z，softmax 把它变成概率，损失是正确类概率的负对数：猜对且很有把握时接近 0，猜错时很大。ArcFace 就是在交叉熵前面改了改 z。 {#t2-k7}

```latex
p_j=\frac{e^{z_j}}{\sum_k e^{z_k}},\qquad L=-\log p_y
```

**8. SGD、动量与 Adam。** SGD：沿梯度反方向走一小步。动量：像滚下山的球，保留上一步的速度，冲过小坑、减少来回震荡。Adam：给每个参数单独调步长（梯度一直很大的参数步子迈小一点）。人脸识别训练大多用 SGD + 动量 0.9（本项目），收敛后泛化通常略好于 Adam；GAN 用 Adam（StarGAN 用 β₁ = 0.5）。权重衰减（weight decay）在每步把权重往 0 拉一点，防止过拟合；BN 和 PReLU 的参数不做衰减。 {#t2-k8}

```latex
v\leftarrow 0.9\,v+\nabla_\theta L,\qquad \theta\leftarrow\theta-\eta\,(v+\lambda\theta)
```

**9. 学习率：先预热，再余弦退火。** 刚开始权重是随机的，大学习率容易把网络"带飞"，所以第一个 epoch 线性地从 0 升到峰值（本项目 0.05，这一段叫 warmup）；之后按余弦曲线平滑降到 0，后期小步精调。 {#t2-k9}

```latex
\eta_t=\frac{\eta_{\max}}{2}\Bigl(1+\cos\frac{\pi\,(t-t_w)}{T-t_w}\Bigr),\quad t\ge t_w
```

**10. 混合精度 bf16。** 用 16 位浮点数做卷积，速度约翻倍、显存减半；bf16 的指数位和 fp32 一样多，数值范围不会溢出，不需要 fp16 那样的损失缩放。本项目在 Intel 核显上实测：ResNet18 训练从 81 张/秒提到 152 张/秒。损失函数部分（acos 等）仍用 fp32 算，保证精度。 {#t2-k10}

### 例题 {#t2-s2}

#### 例题 1|普通卷积 vs 深度可分离卷积的计算量 {#t2-e1}

**28×28 的特征图，输入输出都是 128 通道，3×3 卷积。分别计算乘加次数（MACs）。**

```latex
\begin{aligned}
\text{普通卷积: }&128\times128\times3\times3\times28\times28=115{,}605{,}504\\
\text{深度可分离: }&\underbrace{128\times3\times3\times28\times28}_{\text{逐通道}}+\underbrace{128\times128\times28\times28}_{1\times1}=13{,}748{,}224\\
\text{比值: }&\boxed{8.41\ \text{倍}}
\end{aligned}
```

这就是 MobileFaceNet 只有 0.22 G 次乘加、而 ResNet50 有 6.31 G 次的主要原因（用本项目的网络逐层统计）。

#### 例题 2|IResNet 的特征图尺寸 {#t2-e2}

**112×112 输入，第一层 3×3 卷积步长 1，之后 4 个 stage 各下采样一次。最后的特征图多大？全连接层输入多少维？**

112 → 56 → 28 → 14 → 7，最后一个 stage 有 512 个通道。

```latex
512\times7\times7=\boxed{25{,}088}\ \text{维}\ \xrightarrow{\ \text{全连接}\ }\ 512\ \text{维特征}
```

这一个全连接层就有 25088 × 512 ≈ 1285 万个参数，占 ResNet18 识别模型（约 2400 万参数）的一半多——专题八里"动态量化只量化全连接层"却能让模型从 96 MB 降到 58 MB，原因就在这里。
